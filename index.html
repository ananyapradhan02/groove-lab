how to use ten minutes

pick a groove, set the ladder to start ten beats under where it feels easy, and let it climb four beats every four bars. when it gets messy, stop, drop back, and go again. the next day, start two beats higher.

teachers can build a groove, copy the link, and send it to a student. the link carries the pattern, the tempo and the swing, and nothing else.
